    Density

    Like Stellarium: when the view is wide, only objects that are large on screen or bright enough are drawn; more appear as you zoom in. Messier objects, the selected object and saved targets are always shown.

    Tick a catalog to show it on the sky and in the tables. When several catalogs contain the same object id, the one with the lower priority number is used.

      Import a catalog

      CSV with a header row id,name,type,ra,dec,mag,maj,min,pa (',' ';' or tab). RA in degrees or h:m:s, Dec in degrees or d:m:s, sizes in arcminutes. Types: G, GC, OC, EN, RN, PN, SNR, DN, AST. JSON: a list of such objects.

      One azimuth altitude pair per line (degrees, azimuth from north through east). Stellarium (.txt), NINA (.hrz) and CSV files can be imported. The profile is drawn on the sky, shown in the altitude chart and used for imageable hours.
